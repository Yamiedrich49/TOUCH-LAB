# TOUCH LAB — 3つの数学ゲームを遊び比べる

iPhoneなどのスマートフォン向けに、3種類の数学パズルを1つにまとめた試作版（v0.2）です。

**遊ぶ:** https://yamiedrich49.github.io/TOUCH-LAB/

画面上部のタブから作品を自由に切り替えられます。各5問、合計15問。外部ライブラリ不要で、`index.html` だけで動作します。

## 3つのゲーム

1. **くるり（DOMINO SHIFT）** — 2枚のドミノが作る2×2の範囲をタップして、縦横を反転させる。
2. **くねくね（HINGE MORPH）** — 棒の先端をドラッグして、蝶番でつながる形を変える。
3. **ぴったり（BORDER SCULPT）** — タイルを動かし、金色の点を覆い、全体をつなげたまま輪郭を短くする。
